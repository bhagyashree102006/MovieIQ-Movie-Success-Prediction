# 🎬 MovieIQ

MovieIQ is a Machine Learning web application built using Streamlit.

## Features

- Interactive Dashboard
- Exploratory Data Analysis
- Statistical Tests
- Random Forest Prediction
- Professional UI
- Download Dataset

## Technologies

- Python
- Pandas
- Plotly
- Streamlit
- Scikit-Learn
- SciPy

## Run

streamlit run MovieIQ.py
